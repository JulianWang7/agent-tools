## 9. 时序图规范

### 9.1 时序图的表达目标

在单场景下表达消息顺序与并发结构。

### 9.2 生命线

命名与组件图一致；一条生命线一个职责。

### 9.3 同步消息

实心箭头+激活条；应有返回（显式或图例省略规则）。

### 9.4 异步消息

开放箭头或 `<<async>>`；不隐含同步返回。

### 9.5 返回消息

虚线返回 caller；全文统一方向。

### 9.6 自调用

弯折回同生命线，激活条对齐。

### 9.7 创建与销毁

create/destroy 按场景使用。

### 9.8 片段 alt

互斥分支；各 region 写 `[条件]`。

### 9.9 片段 opt

可选片段；条件为真才执行。

### 9.10 片段 loop

写清循环条件与退出。

### 9.11 片段 par

并行区独立，汇合点清晰。

### 9.12 片段 break

中断后续消息。

### 9.13 片段 critical

临界区与锁/资源名对应（有材料时）。

### 9.14 异常路径

用 alt 或 note；须有接收方处理。

### 9.15 超时

`[超时 T ms]`，T 无材料标 TBD。

### 9.16 重试

loop+条件；次数待确认则标注。

### 9.17 事务与补偿

Saga/事务步骤须与材料一致或标推断。

### 9.18 与用例映射

标题引用用例名或场景 ID。

### 9.19 跨层调用

路径须与架构图允许路径一致。

### 9.20 注释与约束

note 写前置条件，不替代需求正文。

### 9.21 时序反例

50+ 消息无 fragment 应拆图。

### 9.22 评审关注点

返回缺失、par 真实性、与接口矛盾。

### 9.23 时序图检查清单

- [ ] 同步/异步/返回区分清晰
- [ ] alt/opt/loop/par/break/critical 使用正确
- [ ] 含异常/超时/重试（若场景需要）
- [ ] 生命线命名与组件图一致
- [ ] 无虚构消息
- [ ] 默认源文件为 `.puml`；若回退为 `.drawio`，已记录理由并完成 §9.24 的附加检查
- [ ] 导出 SVG 中消息按时间轴**自上而下**排列，**无共线重叠**

### 9.24 时序图工具优先级与回退要求

> 以下为时序图工具选型的权威定义，其余章节若涉及时序图工具选型均引用本节。

| 项 | 要求 |
|----|------|
| **第一选择** | **PlantUML**；源文件为 `docs/diagrams/plantuml/source/{图名}.puml` |
| **第二选择** | **Draw.io MCP**；仅当 PlantUML 难以表达或明确需要精细手工排版时使用，源文件为 `docs/diagrams/drawio/source/{图名}.drawio` |
| **回退记录** | 在评审记录中说明 PlantUML 不适用点、Draw.io MCP 的必要性以及附加目视检查结论 |
| **禁止** | 未记录理由直接跳过 PlantUML；手写拼接不可维护的 Draw.io XML；未检查消息 Y 顺序、生命线挂载和自调用折返就交付 |
| **风险说明** | Draw.io 程序生成时序图时，消息边若未正确挂载到生命线激活条，导出后可能**全部落在同一 Y 高度**（共线），违反 §10.6.2；回退后必须严格目视验收 |
| **PlantUML 导出** | Linux VM：`plantuml -charset UTF-8 -tsvg -o ../rendered source/{图名}.puml` |
| **交付两件套** | `.puml` + `.svg`，或回退场景的 `.drawio` + `.svg`；同一正式图仅保留一份权威源文件 |

**P0 版式缺陷（时序）**：目视或导出 SVG 中 ≥2 条不同顺序的消息箭头共用同一水平线；自调用仅为过短水平短线且无激活条折返。
